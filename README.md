# Valentina Bot 💗 + мини-приложение «Наше»

Telegram-бот-подарок и мини-приложение внутри него, только для двоих.

**Бот** (как и раньше): переписка с админом, «101 причина», плейлист.

**Мини-приложение** (новое):

| Раздел | Что внутри |
|---|---|
| **Таймер** | Отсчёт до дембеля (23.04.2026 → 23.10.2027) с нарисованными нами: она светло-русая, он с короткими каштановыми волосами, в форме. Есть живые часы, процент пройденного пути и полоса «путь домой», где он идёт к ней. Нажатие на большое число переключает дни, недели, месяцы, часы и минуты. Каждый день новая фраза «Любовь — это…». Важные даты (9 июля, 2 ноября, 31 декабря, 3 февраля) можно дополнять. Есть этапы службы. |
| **Питомец** | Сначала выбираете зверька вдвоём: 3 котика, 2 собачки, енотик, хомячок, попугай, черепашка. Все животные нарисованы в SVG, стикеров нет. Питомец появляется, только когда выборы совпали, и каждый выбор приходит в чат. Имя может дать любой из двоих, менять его можно раз в 14 дней. Питомец растёт по 7 стадиям, от «Новорождённого» с соской до «Легенды» в короне. У него есть сытость, радость, энергия и чистота: его можно кормить (любимую еду нужно угадать), играть, мыть, укладывать спать и обнимать. Огонёк, как в TikTok, растёт, если вы оба заходите каждый день. Раз в день питомец приносит подарок: Диме одну из 101 причин, Ксюше тёплую записку. Есть мини-игры «Вкусняшки» и «Пары», а также история роста. Питомец сам гуляет, ловит бабочек, говорит фразы, держит табличку «ещё N дней», ночью спит. Попугай повторяет фразы из вашего чата. |
| **Чат** | Чат для двоих: выбор питомца, реакции, ответы, отметки «прочитано» и «в сети». Если второго нет в приложении, бот присылает ему уведомление. |
| **Важное** | **Хотелки**: прямо или намёком. Хотелку второго можно тайно «забронировать», и он(а) об этом не узнает. **Анкеты**: размеры, любимые цветы, что поднимает настроение. **Письма с замочком**: откроются в выбранную дату или «когда грустно» / «когда скучаешь». **Планы «Когда вернёшься»**: общий чек-лист. |
| **Профиль** | Аватар и имя из Telegram, 7 тем оформления (как в Telegram, светлая, тёмная, персик, лаванда, ночь, мята), настройки уведомлений. |

**Админ** (ADMIN_ID) может больше: удалять любые даты, сообщения и записи, менять имя питомца без ожидания 14 дней, начинать выбор питомца заново и дарить ему опыт.

**Бот сам напоминает** обоим: за неделю, за день и в день важной даты; о вехах дембеля (365, 100, 30, 7, 1 день, половина службы); о том, что питомец проголодался или что огонёк вот-вот погаснет.

## Как это устроено

```
Telegram ──► Бот (Render, Python, aiogram) ──► База Postgres (Neon, бесплатно)
                 ▲  /api/*
                 │
Мини-приложение (Vercel, статичные HTML/CSS/JS)
```

- **Render**: тот же сервис, что и сейчас. В `bot.py` уже был веб-сервер для cron, теперь на нём ещё и API для приложения (`webapp_api.py`). Cron продолжает будить сервис, поэтому API работает круглосуточно.
- **Vercel** отдаёт только страницу приложения. Она никогда не «засыпает» и открывается мгновенно. Запросы `/api/*` Vercel сам пересылает на Render (`webapp/vercel.json`).
- **Postgres** нужен, потому что на бесплатном Render диск временный: после каждого деплоя или перезапуска файлы стираются. Без базы будут теряться питомец, чат и заметки.
- Вход без паролей: Telegram подписывает данные пользователя, сервер проверяет подпись токеном бота и пускает только `ADMIN_ID` и `PARTNER_ID`.

Файлы:

```
bot.py            — бот (+ кнопка приложения, напоминания, запуск API)
webapp_api.py     — API мини-приложения и напоминания
pet.py            — логика питомца (рост, огонёк, характеристики)
storage.py        — хранилище: Postgres (DATABASE_URL) или файл data.json
timeutil.py       — время по Минску
reasons.py        — 101 причина
webapp/           — мини-приложение (это загружается на Vercel)
  index.html, config.js, vercel.json, css/, js/
tools/dev_server.py — запуск приложения локально без Telegram
```

## Настройка: пошагово

### 1. Узнать Telegram ID Димы

После деплоя этой версии напиши боту `/myid`: он ответит твоим ID. Попроси Диму сделать то же самое. Твой ID уже прописан по умолчанию (`1482422281`).

### 2. Создать бесплатную базу (Neon)

1. Зайди на [neon.tech](https://neon.tech), зарегистрируйся (можно через GitHub) и нажми **Create project**.
2. Регион выбери поближе, например **Frankfurt**.
3. На странице проекта нажми **Connect** и скопируй строку подключения вида
   `postgresql://user:password@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`

Таблицу создавать не нужно, бот создаст её сам.

### 3. Переменные окружения на Render

Render → твой сервис → **Environment** → **Add Environment Variable**:

| Переменная | Значение | Обязательно |
|---|---|---|
| `BOT_TOKEN` | токен бота (уже есть) | да |
| `ADMIN_ID` | твой Telegram ID (`1482422281`, уже прописан по умолчанию) | нет |
| `PARTNER_ID` | Telegram ID Димы (`1135275964`, уже прописан по умолчанию) | нет |
| `DATABASE_URL` | строка из Neon | очень желательно |
| `WEBAPP_URL` | ссылка на Vercel, например `https://nashe.vercel.app` (появится в шаге 4) | да |
| `ADMIN_NAME` | `Ксюша` (по умолчанию) | нет |
| `PARTNER_NAME` | `Дима` (по умолчанию) | нет |
| `DMB_START` / `DMB_END` | `2026-04-23` / `2027-10-23` (по умолчанию) | нет |
| `REMIND_HOUR` | час напоминаний по Минску, по умолчанию `10` | нет |

Команда запуска остаётся прежней: `python bot.py`. Новые зависимости (`asyncpg`, `tzdata`) уже добавлены в `requirements.txt`.

### 4. Выложить приложение на Vercel

1. Зайди на [vercel.com](https://vercel.com) через GitHub и нажми **Add New → Project**.
2. Выбери репозиторий `valentina-bot` и нажми **Import**.
3. В **Root Directory** нажми **Edit** и выбери папку **`webapp`**. Это важно.
4. **Framework Preset**: **Other**. Build Command и Output Directory оставь пустыми.
5. Нажми **Deploy**. Через минуту появится ссылка вида `https://valentina-bot-xxx.vercel.app`.
6. Открой `webapp/vercel.json` и проверь адрес Render в строке `destination`. Он должен совпадать с адресом твоего сервиса (Render → сервис → ссылка сверху, например `https://valentina-bot.onrender.com`). Если отличается, исправь и закоммить, Vercel передеплоит сам.
7. Скопируй ссылку Vercel в переменную `WEBAPP_URL` на Render (шаг 3). Render перезапустится.

### 5. Готово

- Напиши боту `/start`. Под приветствием появится кнопка **«✨ Открыть приложение»**, а в меню снизу кнопка **«🐾 Наше приложение»**.
- Слева от поля ввода у вас двоих появится кнопка **«Наше 💞»**, она тоже открывает приложение.
- Команда `/app` присылает кнопку приложения.

Если хочешь отдельную ссылку вида `t.me/твой_бот/app`, зайди в @BotFather → `/newapp` → выбери бота → укажи ссылку Vercel. Это необязательно.

## Как проверить, что всё работает

- `https://<render>.onrender.com/`: ответ `ok, bot is alive 💗`.
- `https://<vercel>.vercel.app/api/ping`: ответ `{"ok": false, "error": "Открой приложение из Telegram 💗"}`. Это нормально: значит, пересылка на Render работает.
- Если в приложении написано «Сервер просыпается…», Render спал. Подожди 30–60 секунд и нажми «Попробовать ещё раз». Cron обычно не даёт ему уснуть.
- «Доступ закрыт» означает, что не указан или указан неверно `PARTNER_ID` / `ADMIN_ID`.

## Локальный запуск (для разработки)

```bash
pip install -r requirements.txt
python tools/dev_server.py
# открой http://localhost:8080/app/?dev=1  (Ксюша)
#        http://localhost:8080/app/?dev=2  (Дима)
```

В этом режиме Telegram не нужен: «сообщения бота» печатаются в консоль, данные пишутся в `dev-data.json`.
`DEV_AUTH=1` включается только в `tools/dev_server.py`. **Никогда не ставь его на Render.**
